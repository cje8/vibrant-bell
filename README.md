# CO₂ → C + O₂: quantum-path problem specification

This repository makes one narrow result reproducible:

> There is no unique, representation-independent "minimum-action path" in the
> full quantum-state space of CO₂.  For a fixed Hamiltonian the exact path is
> the unitary orbit of the initial state; a minimum-energy path (MEP) and a
> molecular instanton are different objects defined on nuclear-coordinate
> potential-energy surfaces.

The best-supported neutral gas-phase **mechanism topology** is

```text
linear O–C–O (X ¹Σg⁺)
  → strongly bent OCO
  → cyclic c-CO₂ (¹A₁)
  → collinear C–O–O (¹Σ⁺)
  → [C(³P) ⊗ O₂(X ³Σg⁻)]S=0
```

This is a candidate reaction tube, not an exact trajectory followed by every
reactive wavepacket.

## Three distinct optimization problems

For a fixed molecular Hamiltonian, the exact state evolution is

```math
|\Psi(t)\rangle=\exp(-i\hat Ht/\hbar)|\Psi(0)\rangle.
```

No path minimization occurs in this equation.  The following constructions
answer different questions:

1. **Projective-Hilbert-space geodesic.**  For normalized endpoint rays,
   `distance = acos(abs(<initial|final>))`.  It is purely geometric and need
   not be generated by the physical CO₂ Hamiltonian.
2. **MEP/IRC.**  A mass-weighted steepest-descent curve on one selected
   Born–Oppenheimer potential-energy surface.  It does not include wavepacket
   splitting or nonadiabatic transitions.
3. **Minimum-action path / instanton.**  A stationary path of a specified
   Euclidean or abbreviated action at a specified temperature or energy.  It
   can differ substantially from the MEP.

The package implements the first construction and an evaluator for a
discretized Euclidean nuclear action.  It deliberately does **not** invent a
CO₂ potential-energy surface.

## What is known for the neutral channel

- The thermochemical threshold for
  `CO₂ → C(³P) + O₂(X ³Σg⁻)` is approximately **11.44 eV**.
- VUV photodissociation between 101.5 and 107.2 nm observed this channel with
  a reported yield of **5 ± 2%** near threshold.
- Published PES calculations support bending, a cyclic CO₂ region, and a
  collinear COO exit.  A later multidimensional PES reports a linear OOC
  minimum about **7.37 eV** above linear OCO and an OCO/OOC connecting barrier
  of about **0.369 eV**.
- The two triplet fragments can couple to total spin `S=0`; individual triplet
  labels therefore do not by themselves require a spin-changing transition.

Here `C` means an isolated carbon atom.  Formation of graphite or another
solid carbon phase is a many-body nucleation/surface problem and is outside the
three-atom molecular Hilbert space.

```bash
PYTHONPATH=src python -m co2_path
```

## Requirements for a defensible full calculation

A quantitative calculation must additionally specify:

- isotopologue, initial rovibronic state, total angular momentum and parity;
- photon energy and pulse, or a microcanonical energy / temperature;
- a global diabatic electronic-state matrix over Jacobi coordinates
  `(R, r, theta)`;
- derivative couplings and, where relevant, spin–orbit couplings;
- asymptotic product projectors resolving O₂ vibration and rotation.

The appropriate result is then a channel-resolved scattering matrix or product
flux.  A "dominant path" may be extracted afterward as a ridge or tube of the
conditional quantum probability current.
